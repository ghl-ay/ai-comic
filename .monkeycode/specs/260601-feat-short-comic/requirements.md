# 短篇漫画功能需求文档

## 1. 需求背景

用户需要一种更轻量、更快速的漫画创作模式，无需角色库依赖，3 步完成创作。

## 2. 需求目标

提供"短篇漫画"快速创作模式：
- 无角色库依赖
- 单章节结构
- 3 步完成创作
- 独立页面，参考现有 CreateChapter.vue 的 tab 模式

## 3. 功能需求

### 3.1 创建流程

#### Tab 1：输入剧情

**REQ-001**: 剧情输入表单，包含：
- 漫画标题（必填）
- 分镜布局：4 格(默认) / 6 格 / 8 格 / 自由布局
- 漫画风格：彩色漫画(默认) / 黑白漫画 / 水彩风格 / 像素风格
- 剧情描述（必填）
- AI 优化提示词按钮

#### Tab 2：生成分镜脚本

**REQ-002**: 分镜脚本生成界面：
- 显示分镜提示词（可编辑）
- 生成分镜脚本按钮
- 脚本预览

#### Tab 3：生成漫画图片

**REQ-003**: 漫画图片生成界面：
- 信息摘要：标题、布局、风格
- 生成漫画图片按钮
- 图片预览
- 完成按钮跳转详情页

### 3.2 页面入口

**REQ-004**: 漫画列表页顶部"创建短篇漫画"按钮

**REQ-005**: 点击列表中的短篇漫画进入编辑模式

### 3.3 显示规则

**REQ-006**: 短篇漫画在列表显示"短篇"标签

**REQ-007**: 点击可编辑已保存内容

## 4. 设计约束

- 基于 Vue 3 + Vite + Vuetify
- 参考 CreateChapter.vue 的 tab 模式实现
- 独立页面，不复用 CreateChapter.vue 的业务逻辑
- 仅复用基础 UI 组件

## 5. 验收标准

- [ ] 能创建短篇漫画
- [ ] 能选择分镜布局和风格
- [ ] AI 优化提示词功能正常
- [ ] 分镜脚本生成功能正常
- [ ] 漫画图片生成功能正常
- [ ] 列表显示"短篇"标签
- [ ] 能编辑已保存的短篇漫画
