# 风格预设库 - 需求文档

## 1. 背景与动机

### 1.1 现状问题

当前系统在风格配置上存在三个核心问题：

1. **创建体验不一致**：创建连载漫画使用自由文本 textarea 输入 `stylePrompt`，创建短篇漫画使用 4 个硬编码选项的 v-select 下拉，两者字段名不同（`stylePrompt` vs `style`）、输入方式不同、默认值不同。
2. **预设极度匮乏**：短篇漫画仅有 4 个硬编码风格选项（彩色漫画、黑白漫画、水彩风格、像素风格），连载漫画无任何预设引导，用户需自行构思风格描述。
3. **后台无法配置**：所有风格选项均硬编码在前端，无法通过后台动态增删改，扩展性为零。

### 1.2 期望效果

- 创建连载漫画和短篇漫画共享同一套风格选择组件和预设数据
- 提供 6 大分类 18 个精选预设风格，覆盖主流漫画创作需求
- 管理员可在后台随时新增、编辑、排序、启停风格预设
- 预设仅是 `style_prompt` 字段的快捷填充机制，不改变底层数据模型和 AI 生成流程

## 2. 核心需求

### REQ-001 风格预设库数据模型

系统应维护一套风格预设数据，每条预设包含以下信息：

| 字段 | 说明 |
|------|------|
| 编码 (code) | 唯一标识，如 `jp_monochrome` |
| 名称 | 展示给用户的名称，如"日漫黑白" |
| 分类 | 所属大类，如"日系漫画" |
| 风格提示词 (style_prompt) | 写入 comics.style_prompt 的实际值 |
| 描述 | 补充说明，tooltip 中展示 |
| 封面图 | 预设风格的示例图 URL |
| 排序权重 | 同分类内的展示顺序 |
| 启用状态 | 是否对用户可见 |

### REQ-003 统一风格选择组件

当用户在创建连载漫画、创建短篇漫画、编辑漫画风格时，应使用同一套风格选择交互组件：

1. **预设选择模式**：用户可从分类 tab 中选择预设风格，选中后自动填充 `style_prompt`
2. **自定义模式**：用户可手动输入自定义 style_prompt 文本
3. **AI 辅助模式**（仅连载漫画保留）：可 AI 一键生成风格描述
4. 两种模式可切换，预设选择后仍可编辑微调

### REQ-004 前后端字段名统一

将创建短篇漫画的字段名从 `style` 统一为 `stylePrompt`，与连载漫画保持一致，后端 API 参数名也统一。

### REQ-005 后台风格预设管理

提供后台管理 API，支持：

- 新增风格预设
- 编辑风格预设（名称、分类、提示词、封面图、排序等）
- 启用/停用风格预设
- 删除风格预设
- 查询风格预设列表（支持按分类筛选）

### REQ-006 默认值统一

消除三处不一致的默认值，统一为一个来源：

| 当前位置 | 当前默认值 | 统一后 |
|---------|----------|-------|
| 连载漫画图片生成 | `'日系黑白漫画'` | 从 code='jp_monochrome' 的预设中取 |
| 短篇漫画图片生成 | `'彩色漫画'` | 同上 |
| 小说风格分析回退 | `'日系黑白漫画风格'` | 同上 |

**稳定性保证**：使用固定的预设编码 `jp_monochrome` 作为默认值，即使排序调整也不会变化。若该预设被停用或删除，降级为硬编码值 `'日系黑白漫画风格'`。

## 3. 兼容性需求

### REQ-007 向后兼容

- 预设是 `style_prompt` 字段的快捷填充机制，不改变 comics 表结构
- 已有漫画的 `style_prompt` 值不受影响，即使其值不在预设列表中也能正常使用和编辑
- 不改变 AI 图片生成流程，`style_prompt` 仍然以相同方式嵌入 prompt
- 前端风格选择组件是纯 UI 层变更，不影响数据写入逻辑

### REQ-008 数据迁移

- 将 18 个预设风格作为种子数据写入数据库初始化脚本
- 现有短篇漫画的硬编码 4 选项映射到新预设：
  - `'彩色漫画'` → `jp_color`（日漫彩漫）
  - `'黑白漫画'` → `jp_monochrome`（日漫黑白）
  - `'水彩风格'` → `special_watercolor`（水彩风）
  - `'像素风格'` → `cartoon_pixel`（像素风）

## 4. 非功能性需求

### REQ-009 性能

- 预设列表 API 响应时间 < 200ms
- 单表查询，无复杂关联，性能可接受

### REQ-010 分类管理方案

**本期方案（MVP）**：分类信息仅存储在 style_presets 表的 category 字段中，不建独立的分类表。

- 分类由预设数据自然形成，通过 `SELECT DISTINCT category` 查询获得
- 分类排序权重取该分类下首个预设的 sort_order
- 管理员可通过编辑预设的 category 字段间接管理分类
- 删除预设时，若某分类下无预设，该分类自动消失

**未来扩展方向**（本期不实现）：
- 新建 style_categories 独立表，支持分类图标、分类描述
- 支持分类排序、分类启用/停用
- 支持分类级别的元数据配置

### REQ-011 预设可扩展性

- 分类可扩展：管理员可通过编辑预设间接管理分类（见 REQ-010）
- 预设可扩展：每个分类下的预设数量不限
- 预设字段可扩展：未来可增加示例图、标签等字段

## 5. 用户体验

### REQ-012 创建漫画时的风格选择

在创建漫画对话框中：

1. 默认展示预设选择模式，按分类 tab 展示预设卡片
2. 点击预设卡片选中，卡片高亮，`style_prompt` 自动填充
3. 可切换到"自定义"tab，手动输入风格描述
4. 可点击 AI 按钮生成风格描述
5. 风格为可选项，可不选择直接创建

### REQ-013 创建短篇漫画时的风格选择

在创建短篇漫画页面中：

1. 替换当前 4 选项 v-select，使用统一的风格选择组件
2. 交互方式与创建连载漫画一致
3. 默认选中第一个启用的预设风格

### REQ-014 编辑漫画风格时

在漫画详情页编辑风格时：

1. 保留当前 textarea 编辑方式
2. 在 textarea 上方增加"从预设选择"按钮，点击弹出预设选择面板（见 REQ-015）
3. 选择预设后填充 textarea，用户仍可手动修改

### REQ-015 预设选择面板交互细节

**弹出方式**：使用 v-dialog 组件（模态对话框）

**布局参数**：
- 对话框宽度：800px（桌面端），90vw（移动端）
- 最大高度：70vh，内容区域滚动
- 位置：居中显示

**组件结构**：
```
┌─────────────────────────────────────────────────────────────┐
│  选择风格预设                                          [×]  │ ← 标题栏
├─────────────────────────────────────────────────────────────┤
│  ┌──────────┬──────────┬──────────┬──────────┐             │
│  │ 预设风格  │ 自定义    │ AI生成   │             │ ← 模式tab
│  └──────────┴──────────┴──────────┴──────────┘             │
├─────────────────────────────────────────────────────────────┤
│  [日系漫画] [国风] [美系漫画] [卡通/绘本] [写实/照片] ...   │ ← 分类tab
├─────────────────────────────────────────────────────────────┤
│  ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐                  │
│  │ [图]  │ │ [图]  │ │ [图]  │ │ [图]  │                  │
│  │ 日漫  │ │ 日漫  │ │ 少女  │ │ Q版   │ ← 预设卡片网格    │
│  │ 黑白  │ │ 彩漫  │ │  漫   │ │ 萌系  │   (2-4列响应式)  │
│  └───────┘ └───────┘ └───────┘ └───────┘                  │
│  ┌───────┐ ┌───────┐                                      │
│  │ [图]  │ │ [图]  │                                      │
│  │ ...   │ │ ...   │                                      │
│  └───────┘ └───────┘                                      │
├─────────────────────────────────────────────────────────────┤
│  当前风格: 日系黑白漫画风格，精细线稿...                     │ ← 当前选中展示
│  [取消]                                          [确定]    │ ← 操作按钮
└─────────────────────────────────────────────────────────────┘
```

**预设卡片设计**：
- 尺寸：150px × 180px（桌面），120px × 150px（移动端）
- 内容：封面图（占 60%）+ 名称 + 简短描述（悬停显示）
- 选中态：蓝色边框 + 勾选图标
- 悬停态：阴影加深 + 显示完整描述

**自定义 tab**：
```
┌─────────────────────────────────────────────────────────────┐
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 请输入风格描述...                                    │   │
│  │                                                     │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│  提示：描述画面风格、线条特点、色彩倾向等                   │
└─────────────────────────────────────────────────────────────┘
```

**交互流程**：
1. 点击"从预设选择"按钮 → 打开对话框
2. 默认显示"预设风格" tab，选中第一个分类
3. 点击预设卡片 → 卡片高亮，底部显示当前风格描述
4. 点击"确定" → 关闭对话框，填充 style_prompt 到 textarea
5. 点击"取消"或外部区域 → 关闭对话框，不保存
6. 切换到"自定义" tab → 显示 textarea，手动输入
7. AI 生成 tab（仅连载漫画可用）→ 调用 AI 生成接口

**移动端适配**：
- 分类 tab 横向滚动（小屏无法全部展示）
- 预设卡片改为 2 列布局
- 对话框改为全屏或底部弹出（v-dialog--fullscreen）

## 6. 约束与边界

- 本期不实现风格预设的示例图生成功能，封面图由管理员手动上传
- 本期不实现风格预设的多语言支持
- 本期不实现用户自定义预设的收藏/最近使用功能
- 预设选择不影响 AI 生成流程的其他参数（如分镜格数、角色设定等）
