# 导出漫画 PDF 功能设计

## 概述

在漫画详情页的"预览漫画"按钮右边新增"导出漫画"按钮，点击后下载包含所有章节漫画图片的 PDF 文件。

## 需求

- 导出按钮位于"预览漫画"按钮右侧
- 点击后生成 PDF，包含所有有图片的章节
- PDF 按章节顺序排列图片，每页一张
- 文件名格式：`{漫画标题}-{YYYY-MM-DD}.pdf`
- 无图片时提示用户

## 技术方案

### 依赖

使用 `jspdf` 库在前端生成 PDF。

### 实现位置

- 文件：`web/src/views/ComicDetail.vue`
- 按钮：在"预览漫画"按钮后添加"导出漫画"按钮

### PDF 生成流程

1. 过滤有 `page_image` 的章节
2. 按 `chapter_number` 升序排列
3. 创建 jsPDF 实例
4. 依次加载图片并添加到 PDF
5. 下载 PDF 文件

### 错误处理

| 场景 | 处理 |
|------|------|
| 无图片 | 显示 snackbar 提示 |
| 图片加载失败 | 跳过继续处理 |
| 生成失败 | 显示错误提示 |

## 测试要点

- 无章节时点击导出
- 有章节但无图片时点击导出
- 正常导出下载 PDF
- PDF 内容顺序正确
