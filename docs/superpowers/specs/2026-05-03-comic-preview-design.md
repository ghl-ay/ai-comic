# 漫画预览功能设计文档

## 功能概述

在章节创建页面添加「预览漫画」按钮，点击后打开全屏图片预览弹窗，可以浏览当前漫画的所有章节图片。

## 界面设计

### 按钮位置

- 位于面包屑导航行右侧（标题后面）
- 按钮样式：包含图标和文字「预览漫画」
- 始终显示，无图片时点击给出提示

### 全屏预览弹窗

- 深色背景遮罩
- 图片等比例最大化居中显示
- 左右切换箭头按钮
- 右上角关闭按钮（×）
- 底部显示当前页码（如：1 / 3）

## 技术方案

### 组件选型

使用 **vue-easy-lightbox**（Vue 3 图片预览库）：
- 内置键盘快捷键（←→切换、ESC关闭）
- 支持滚轮缩放、双击放大
- 支持点击遮罩关闭
- 轻量（~10KB gzipped）

### 数据来源

- 获取当前漫画的所有章节列表
- 过滤出有 `page_image` 的章节
- 按 `chapter_number` 升序排列
- 初始显示定位到当前正在编辑的章节

### 无图片处理

点击预览按钮时，如果没有任何章节图片，显示 SnackBar 提示「暂无漫画图片」。

## 交互支持

### 导航操作

- `←` `→` 键盘切换章节
- 点击左右箭头切换
- `ESC` 关闭预览
- 点击遮罩区域关闭

### 缩放操作

- 滚轮缩放图片
- 双击放大/还原

## 实现步骤

1. **安装依赖**：`npm install vue-easy-lightbox`
2. **创建预览组件**：新建 `ComicPreview.vue`，封装 vue-easy-lightbox 和章节切换逻辑
3. **添加 API 调用**：在 CreateChapter.vue 中获取漫画章节列表
4. **集成到页面**：在 CreateChapter.vue 添加按钮和预览组件

## 文件变更

| 文件 | 变更类型 | 说明 |

| `web/package.json` | 修改 | 添加 vue-easy-lightbox 依赖 |
