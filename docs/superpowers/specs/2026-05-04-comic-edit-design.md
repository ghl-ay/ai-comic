# 漫画标题和风格编辑功能设计

## 背景

当前用户创建漫画后无法修改标题和风格提示词，需要添加编辑功能。

## 需求

- **标题**：支持行内编辑，点击进入编辑模式，失焦自动保存
- **风格**：通过弹窗编辑，显式点击保存

## 技术方案

后端 API 已完备（`PUT /api/comics/:id` 支持 `title` 和 `stylePrompt`），只需修改前端。

### 修改文件

`web/src/views/ComicDetail.vue`

### 标题行内编辑

**新增状态变量：**
```javascript
const editingTitle = ref(false)
const editTitleValue = ref('')
```

**UI 改动：**
- 标题区域用 `v-if/v-else` 切换显示/编辑状态
- 显示状态：标题文字 + 编辑图标提示
- 编辑状态：`v-text-field` 输入框

**交互逻辑：**
1. 点击标题进入编辑模式，自动聚焦并全选文字
2. 失焦或 Enter 键触发保存
3. Escape 键取消编辑
4. 保存时调用 API，失败则恢复原值并提示错误

### 风格弹窗编辑

**新增状态变量：**
```javascript
const styleDialog = ref(false)
const editStyleValue = ref('')
```

**UI 改动：**
- 风格显示区域旁边添加"编辑"按钮
- 新增编辑风格对话框（`v-dialog`），包含 `v-textarea` 和保存/取消按钮

**交互逻辑：**
1. 点击"编辑"按钮打开弹窗，填充当前风格值
2. 点击"保存"调用 API，成功后关闭弹窗
3. 点击"取消"关闭弹窗不保存

## 成功标准

1. 用户可以在漫画详情页点击标题进行编辑，失焦后自动保存
2. 用户可以点击"编辑风格"按钮在弹窗中修改风格提示词
3. 保存失败时显示错误提示，不丢失数据
